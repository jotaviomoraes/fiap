# config

Arquivos de configuracao e parametros do projeto.

| Arquivo | Descricao |
|---|---|
| `requirements.txt` | Dependencias Python do projeto (unico arquivo, para todos os modulos). Instalar com `pip install -r config/requirements.txt`. |
| `.env.example` | Modelo das variáveis de login do dashboard e da integração Oracle opcional. Credenciais reais não devem ser versionadas. |
