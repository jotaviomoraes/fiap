# RNN/LSTM — Jupyter e PyTorch local

Abra RNN_LSTM_AppInterativo_v4(1).ipynb e execute as células em ordem com o kernel **Python (FASE7)**. O notebook contém a implementação PyTorch em células editáveis: sentimento IMDB/B2W, laboratório de memória e geração Machado de Assis.

Instalação e GPU: consulte [README_LOCAL.md](../README_LOCAL.md). As dependências foram centralizadas em ../requirements-local.txt; instale a build CUDA do PyTorch separadamente conforme esse guia.

O script rnn_lstm_app.py continua como alternativa standalone. Ele treina ao executar/importar; para Jupyter, prefira o notebook. A interface abre localmente. Os datasets ficam em data/.
